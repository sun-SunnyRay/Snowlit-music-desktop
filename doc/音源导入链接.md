> 本地测试不准时，优先用本页链接。

---

## 使用方法（映雪 / 洛雪通用）

1. 打开 App → **设置** → **音源管理 / 自定义源** → **在线导入**
2. 把下方 **任意一条 raw 链接** 整行粘贴进去
3. 导入成功后：**只开 1～2 个优质源** 先试听（不要一次全开）
4. 若 `raw.githubusercontent.com` 打不开，用文末 **镜像前缀** 包一层

## 五、GitHub 打不开时的镜像写法

在 **原 raw 链接前面** 加代理前缀（任选其一能通的）：

```
https://ghproxy.net/
https://gh.llkk.cc/
https://github.moeyy.xyz/
https://ghproxy.cn/
```

**示例（SixYin）：**

```
https://ghproxy.net/https://raw.githubusercontent.com/pdone/lx-music-source/main/sixyin/latest.js
```

**示例（玉宁熙 V1.2.2）：**

```
https://ghproxy.net/https://raw.githubusercontent.com/guoyue2010/lxmusic-/main/V260810/推荐/lx-玉宁熙V1.2.2.js
```

hwxlikemi 仓库自带写法（可替换文件名）：

```
https://raw.kkgithub.com/hwxlikemi/lxs/main/念心音源-V1.0.1.js
```

## 六、建议导入顺序（少而精）

| 优先级 | 音源 | 说明 |
|--------|------|------|
| 1 | 墨澜 / 星海 / HYW | V260810 官方推荐，先试 |
| 2 | 玉宁熙 | 质量高，可能要 Key |
| 3 | SixYin / Flower / Huibq | pdone 稳定 latest |
| 4 | QDY / Juhe / 念心 | 聚合类，按个人网络择优 |

**注意**

- 第三方音源后端会挂、会限速、会要 Key，属正常现象  
- 同时启用过多源会拖慢试听与换源  
- 资源仓库：  
  - https://github.com/guoyue2010/lxmusic-  
  - https://github.com/pdone/lx-music-source  
  - https://github.com/Macrohard0001/lx-ikun-music-sources  
  - 资源站：https://yy.guoyue2010.com/
