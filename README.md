映雪音乐在洛雪音乐（LX Music）桌面版之上继续演进：保留检索、播放、歌单与歌词等既有能力，并补足账号歌单同步、歌词点选跳转、设置项收敛，以及独立的映雪品牌与数据目录。本仓库仅发布播放器，不附带音源。

## 功能概览

| 能力 | 说明 |
| --- | --- |
| 检索与播放 | 主页检索歌曲，歌单页检索歌单。热门检索与历史检索置于顶栏下拉，以免占据主界面。 |
| 歌词 | 于播放详情中点选一句歌词，即可跳转至对应进度。默认启用歌词翻译，并记忆上次播放位置。 |
| 桌面歌词 | 歌词可独立浮于桌面，并提供锁屏、置顶等选项。 |
| 账号歌单 | 支持登录网易云、QQ 音乐与酷狗。登录后，账号歌单写入「我的列表」；QQ 红心歌曲归入「QQ音乐 · 收藏」。 |
| 下载与主题 | 支持下载，并可优先选用更高音质；嵌入歌词时仅标注映雪。内置多套主题，亦可自行添加。 |

## 相对洛雪音乐的演进

洛雪音乐桌面版已具备完整的播放能力。映雪在此基础上所作调整如下。

1. **账号歌单写入本地列表。** 登录网易云、QQ 音乐或酷狗后，账号歌单直接出现于「我的列表」，无需仅依赖手动收藏。
2. **歌词点选跳转。** 于播放详情中点选一行歌词，即可跳转进度，而不必只依靠拖动进度条。
3. **设置项收敛。** 数据同步、开放 API、网络代理与软件更新等入口不再列于设置之中；启动时亦不弹出更新日志。
4. **检索交互调整。** 主页专用于歌曲检索，热门与历史检索置于顶栏。热门检索、历史检索、歌词翻译与播放进度记忆默认开启。
5. **品牌与数据目录独立。** 界面、协议与数据目录均按映雪独立维护，不再指向洛雪官方更新或官方链接。
6. **安装包不预置音源。** 发行包不预装推荐源，亦不会在启动时自动写入。播放是否可用，取决于使用者自行导入的源。

## 构建

需使用 Node.js 22 或更高版本。于 Windows 编译原生模块时，另需 Visual Studio 2022 Build Tools。

```bash
npm install
npm run dev
```

亦可使用仓库内的 `dev-with-vs.bat`，该脚本会先行加载 `vcvars64`。

## 发行

```bash
npm run pack:win:setup:x64
```

安装包生成于 `build/` 目录，例如 `snowlitmusic-desktop-v6.0.27-x64-Setup.exe`。默认关闭自动更新。

Windows 用户数据位于 `%APPDATA%/snowlitmusic-desktop`。
