# 映雪音乐 · 桌面版

映雪音乐（Snowlit Music）是一款 Windows 桌面播放器。在洛雪音乐（LX Music）桌面版的基础上二次开发，留下好用的播放能力，再补上账号歌单、歌词点选、更干净的设置和映雪自己的界面。

当前版本 6.0.27。

## 它能做什么

- **搜歌、听歌、管歌单**：主页搜歌曲，歌单页搜歌单。热门搜索和历史搜索收在顶栏下拉里，不占主页。
- **歌词**：播放详情里点某一句，进度会跳到那一句。默认打开歌词翻译，并记住上次听到哪。
- **桌面歌词**：可以单独浮在桌面上，锁屏、置顶这些选项都还在。
- **账号歌单**：侧栏登录网易云、QQ 音乐、酷狗。登录后把账号里的歌单写到「我的列表」。QQ 红心歌会进「QQ音乐 · 收藏」。
- **下载与音质**：支持下载，可优先选更高音质。嵌入歌词时只带映雪。
- **主题**：自带多套皮肤，也可以自己加。
- **自定义源**：在线导入或本地导入你自己的源。仓库不附带任何音源。

## 相对洛雪，映雪多做了什么

洛雪本身已经是很完整的播放器。映雪在它上面继续改，主要是这几件事：

1. **账号进列表**。不用只靠手动收藏。网易云、QQ、酷狗登录后，歌单直接出现在「我的列表」。
2. **歌词可以点**。播放详情里点一行歌词就能跳进度，不用只靠拖进度条。
3. **设置更干净**。数据同步、开放 API、网络代理、软件更新这些入口不再摆在设置里，启动也不再弹更新日志。
4. **搜索更好用**。主页专心搜歌，热门和历史放到顶栏。热门搜索、历史搜索、歌词翻译、记住播放进度默认打开。
5. **品牌是映雪**。界面、协议、数据目录都按映雪来，不再指向洛雪官方更新或官方链接。
6. **不内置音源**。安装包不会预装推荐源，也不会开机自动写入。播不播得了，只取决于你自己导入的源。

## 使用前请先读

- 本仓库**只发布播放器**。不附带音源脚本，也不提供导入链接清单。
- 克隆或打包之后还不能直接听歌。请到 **设置 → 基本设置 → 自定义源**，用「在线导入」或「本地导入」。
- 播放器不会去官方平台拿音频文件。它只把歌名、歌手等信息交给你选中的源；源返回什么链接，播放器就按这个链接播。链接对不对、能不能播、是否侵权，播放器无法校验，也不负责。
- 导入来路不明的源脚本可能影响你的系统，请自己判断风险。
- 使用过程中产生的封面、音频等版权数据，请在 24 小时内自行清除。
- 本项目面向个人学习交流，完全免费。请遵守你所在地的法律法规，尊重版权，支持正版。

没有导入可用的自定义源时，搜索和播放都会失败。这是预期行为，不是安装损坏。

## 开发

需要 Node.js 22 或更高版本。在 Windows 上编译 native 模块时，还需要 Visual Studio 2022 Build Tools。

```bash
npm install
npm run dev
```

也可以用仓库里的 `dev-with-vs.bat`，它会先加载 `vcvars64`。

## 打包

```bash
npm run pack:win:setup:x64
```

安装包会生成在 `build/`，例如 `snowlitmusic-desktop-v6.0.27-x64-Setup.exe`。默认关闭自动更新。

Windows 用户数据大致在 `%APPDATA%/snowlitmusic-desktop`。
